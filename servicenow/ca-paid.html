Troubleshooting

Why do I see GitHub 404?

For a private repository, 404 usually means the current GitHub account has not been invited, the invitation is still pending, or you are signed in to a different account. Send the exact username, accept the invitation, then try again.

I paid, but no invitation arrived.

Confirm the username you sent, check GitHub notifications and spam email, and contact the seller through the Whop order conversation with the order receipt. Do not send passwords or access tokens.

Can this page grant access automatically?

No. This static page cannot verify a Whop payment or change GitHub permissions. Access must be granted by the seller or a separately configured secure server integration.

What happens after a refund or subscription expiry?

Future repository access and updates may be removed according to the product terms. Removing repository access cannot remotely delete copies downloaded earlier, and retained copies remain subject to the license.
